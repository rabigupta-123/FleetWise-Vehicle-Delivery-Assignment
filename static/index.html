DRIVER SMARTPHONE GPS TRACKING PORTAL

Authorize and stream real smartphone browser GPS fixes into FleetWise via HTML5 Geolocation API.

Checking Context... Location permission not requested GPS tracking stopped
Secure context unavailable (Geolocation disabled by mobile browser policy)

Modern mobile browsers (iOS Safari, Android Chrome) strictly require a Secure Context (HTTPS or localhost) to grant physical GPS access. When accessing via plain HTTP on a LAN IP (e.g. http://192.168.x.x:8000), the browser will permanently block location requests.
Solutions: Use Local HTTPS (https://<LAN-IP>:8443 via scripts/start_https.bat) or launch a secure public tunnel via scripts/share_online.bat.

Explicit Privacy & Consent Notice: By clicking "Start GPS Tracking", your browser will request permission to access your device's physical GPS location. Location fixes (coordinates, accuracy, speed, heading) are streamed securely to the FleetWise backend only while tracking is active. You can stop tracking at any time.
